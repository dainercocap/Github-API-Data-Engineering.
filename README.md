# GitHub API Data Engineering

## Project Overview

This project uses the GitHub Public API to extract user information and process it using Databricks and PySpark.

## Technologies

- Databricks
- Python
- PySpark
- SQL
- Delta Lake
- GitHub API

## Project Structure

- `01_Github_API_Pipeline`: API data extraction and Bronze ingestion.
- `02_Silver_transformation`: Data cleaning and Silver transformation.

## Architecture
